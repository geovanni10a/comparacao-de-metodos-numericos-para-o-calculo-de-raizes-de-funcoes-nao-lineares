# Código de conduta

Este projeto acadêmico deve ser um espaço respeitoso e acolhedor para todas as pessoas, em qualquer
nível de experiência.

## Comportamento esperado

- Tratar as pessoas com respeito e usar linguagem acolhedora.
- Criticar ideias e código de forma construtiva, nunca as pessoas.
- Aceitar correções e dar crédito ao trabalho alheio.

## Comportamento inaceitável

- Assédio, insultos, discriminação ou ameaças de qualquer tipo.
- Publicação de dados pessoais de outras pessoas sem autorização.
- Plágio ou falsificação de resultados.

## Aplicação

Situações inaceitáveis podem ser informadas à pessoa responsável pelo repositório,
[geovanni10a](https://github.com/geovanni10a). Comentários, commits e contribuições que violem este
código podem ser removidos, e quem os fez pode ser impedido de participar do projeto.

Este código vale em todos os espaços do projeto no GitHub.
